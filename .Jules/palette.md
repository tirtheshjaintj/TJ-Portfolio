## 2025-11-02 - Accessible Floating Action Buttons & Chatbot Controls
**Learning:** In portfolio apps with floating action triggers (FABs) styled using utility classes like `.float` on non-semantic `<div>` elements or icon-only `<button>` tags without text, screen readers and keyboard users cannot identify the button's purpose or interact via standard keystrokes. Replacing `div` wrappers with semantic `<button type="button">`, adding dynamic `aria-label`/`aria-expanded`, and providing accessible control buttons for nested modal actions (clear history, close) creates an intuitive, accessible experience without altering visual design.
**Action:** When working on floating utility triggers or icon-only UI widgets, always use semantic `<button>` tags with explicit `aria-label`, hover `title`, and stateful ARIA attributes (`aria-expanded`, `aria-hidden`, `aria-live`).
